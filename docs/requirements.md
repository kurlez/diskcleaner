# 磁盘清理工具 需求设计 v0.3

## 已确认决策
- 平台：仅 Windows 10 22H2 / Windows 11（不支持更老版本）
- 形态：桌面 GUI，Tauri 2（Rust 后端）+ Svelte + TypeScript
- 界面语言：中英双语（i18n）
- 权限：MVP 采用方案 A —— manifest `requireAdministrator`，整个应用以管理员运行
  - 前端只加载本地打包资源，禁用外部导航；Tauri capabilities 最小化
  - 后续可演进为方案 B（普通权限主程序 + 提权 helper，命名管道通信）

## 工程结构
- `crates/core`：路径安全、扫描、规则、清理编排（与 GUI 解耦，可在任意平台单测）
- `crates/cli`：调试/测试入口
- `app/`（M3）：Tauri + Svelte

## 功能（优先级）
**P0（MVP）**：磁盘概览；扫描与分析（目录树、Top N、treemap）；Windows 规则集一键清理
（用户/系统临时文件、回收站、缩略图缓存、崩溃转储、Windows 更新下载缓存、传递优化缓存、
浏览器缓存、开发者缓存、旧日志、Windows.old）；预览→确认→执行→报告；保护名单、dry-run、
操作日志、历史与恢复；设置（排除路径、规则开关、过期天数）。

**P1**：重复文件；USN Journal 增量扫描；系统工具封装（休眠文件、还原点/卷影副本、
`DISM /StartComponentCleanup`，禁止手动删 WinSxS）；卸载残留。

**P2**：定时清理、低空间提醒、自定义规则（YAML）。

## 硬性安全约束
1. 保护名单默认拒绝：系统目录、Program Files、ProgramData、用户配置文件及文档/桌面/图片等；
   仅更具体的"允许根"（如 `C:\Windows\Temp`）内部可删（已在 `safety.rs` 实现并测试）。
2. 不跟随重解析点（symlink/junction/挂载点）。
3. 跳过 OneDrive 等云占位文件。
4. 硬链接不重复计数；长路径用 `\\?\`；处理 ADS。
5. 被占用文件跳过并记录，不强杀进程。
6. 删除前二次校验路径（防 TOCTOU）；调用方须先取规范长路径（8.3 短名会被拒绝）。
7. 默认移入回收站；永久删除需单独确认。
8. 全程本地，不联网。

## 非功能
- 1TB NTFS：MFT 扫描 ≤ 30 秒出完整树；遍历模式几分钟内先出部分结果
- 后台线程 + 事件流，UI 不卡顿
- 清理前写 intent log，崩溃后可追溯
- 发布：MSI/NSIS + 代码签名

## M2 设计要点
- 规则 = 路径模板（`%VAR%`、目录名通配符）+ 名称过滤 + 最小年龄 + 风险等级 + 删除方式。
- 流程：`build_plan`（只读）→ 用户确认 → `execute`（逐项二次校验、先写日志再删除）。
- 展开路径时：基路径取规范长路径（环境变量常含 8.3 短名）；途中任一级是链接/junction 的目标直接丢弃。
- 计划项含受保护名称（`.git` 等）或云占位文件则整项跳过；修改时间取子树内最新者。
- 用户排除项（`SafetyPolicy::exclude`）优先级最高，规则的允许根无法覆盖。
- 操作日志为 JSON Lines（`intent` 在前，`result` 在后）；日志写不进去则中止，不做"无日志删除"。
- 回收站不释放空间：报告分开统计 `freed_bytes` 与 `recycled_bytes`；
  内置规则清理的都是可再生数据，默认 `Permanent`，可用 `--recycle` 覆盖。
- 未纳入 M2：清空回收站、`Windows.old`、`DISM`、休眠文件、卷影副本、停止 `wuauserv`（M5 的"系统动作"）。

## M3 设计要点
- 结构：`app/src-tauri`（Tauri 2 后端）+ `app/`（Svelte 5 + TS + Vite 前端）。
  后端逻辑集中在 `service.rs`（与 Tauri 无关，可单测），`lib.rs` 只做命令封装。
- **前端只能提交规则 ID**；真正要删除的路径始终来自后端保存的计划，且计划一次性有效。
- 长任务（扫描、分析、执行）在阻塞线程池运行，通过 `scan-progress` / `clean-progress` 事件推送进度，可取消。
- 扫描结果保留在后端，目录树按需懒加载（每层最多 1000 项）。
- 错误以 `{code, detail}` 返回，由前端按 `err.<code>` 翻译。
- i18n：`zh` / `en` 两套词典，单测校验键集合、占位符一致，且覆盖所有规则、跳过原因与错误码。
- 管理员权限：发布版（release）嵌入 `requireAdministrator` manifest；开发版不加，否则 `tauri dev` 无法启动。
- 安全：严格 CSP；capabilities 只开放事件监听；前端不加载任何外部资源。
- 浏览器里 `npm run dev` 会使用 `lib/mock.ts` 的模拟数据预览界面；发布版不含 mock。
- 暂未做：treemap 可视化与 MFT 快速扫描（M4）、"清空回收站"等系统动作（M5）。

## M4 设计要点
- **MFT 快速扫描**（`crates/core/src/mft.rs`）：基于 `ntfs` crate 顺序遍历 `$MFT`，只依赖 `Read + Seek`，
  因此可用磁盘镜像在任何平台测试。原始卷读取经 4 KiB 对齐、1 MiB 预读的缓存读取器，满足裸卷对齐要求。
- 大小语义：MFT 模式统计**磁盘占用**（已分配的簇，稀疏段不计）；遍历模式统计逻辑大小。界面用徽章标明当前方式。
- 硬链接只出现一次且只算一次；DOS 8.3 短名、扩展记录、已删除记录被忽略；备用数据流与目录索引不计入。
- 回退：非管理员（拒绝访问）、非 NTFS、路径不在索引中时，自动改用遍历扫描，并在界面提示原因。
- 测试夹具：`crates/core/tests/fixtures/sample.ntfs.gz` 是用 ntfs-3g 生成的真实 NTFS 镜像
  （嵌套目录、300 个小文件、硬链接、10 MiB 稀疏文件、中文名、已删除文件），
  由 `make_ntfs_fixture.sh` 复现；`sample.expected.tsv` 是挂载后用 `find` 得到的期望清单。
- **Treemap**：`lib/treemap.ts` 实现 squarified 算法（有单测：面积守恒、不重叠、长宽比、退化输入），
  组件支持点击钻取、路径面包屑、过小条目合并为"其他 N 项"；与列表视图共享同一份后端扫描结果。
- 暂未做：USN Journal 增量扫描（M5）；MFT 模式下的"已跳过"统计为空。

## M5 设计要点
- **重复文件**（`duplicates.rs`）：按大小 → 前 64 KiB 哈希 → 完整 blake3 哈希逐级筛选；
  不跟随链接、跳过云占位文件；硬链接合并为一份（删掉其一并不释放空间，不算重复）；
  按"可释放空间"排序；推荐保留修改时间最早的一份。
- **删除重复文件的安全链**：前端只回传（组序号, 文件序号）；后端校验
  ① 每组至少保留一份、保留的那份仍在且未变；② 被删文件的大小和修改时间与扫描时一致；
  任何一项不满足就整体拒绝。执行走同一个执行器（二次校验、先写日志）。
  默认移入回收站。
- **"用户亲自选中"策略**（`SafetyPolicy::for_user_selected`）：不保护文档/桌面/下载等用户自己的目录，
  但系统目录、程序目录、`ProgramData`、回收站内部、`AppData` 与受保护名称（`.git`、`.ssh`）依旧拒绝；用户排除项依旧最优先。
- **系统动作**（`sysaction.rs`）：清空回收站、关闭休眠、`DISM /StartComponentCleanup`、
  删除 `Windows.old`（`takeown` + `icacls`，管理员组用 SID `S-1-5-32-544` 以免依赖语言，再删除）、删除最早的卷影副本。
  全部经可注入的 `CommandRunner`，因此命令行构造、执行顺序、失败时是否继续都有测试；
  每项单独确认、写入操作日志，并以系统盘可用空间的前后变化报告实际释放量。
  不手动删除 `WinSxS`。
- **服务停启**：规则可声明需要停止的服务（`windows_update_cache` → `wuauserv`、`bits`）。
  执行器在该规则的文件前后停止/恢复，只恢复"我们自己停掉的"，取消或出错同样恢复；dry-run 不碰服务；
  服务状态读取用 `sc query` 的数字状态码，不依赖界面语言。
- **顺延**：USN Journal 增量扫描（需要持久化扫描缓存与 `FSCTL_READ_USN_JOURNAL` 的 unsafe 封装，
  又无法在 Linux 上验证，宁可单独做）→ M7。

## M6 应用卸载与残留清理（参考 Geek Uninstaller 的公开工作流）
流程：**列出已装程序 → 运行程序自带的卸载器 → 深度扫描残留 → 用户勾选 → 备份注册表后删除**；
卸载器缺失或损坏时可"强制删除"。

- **已装程序**：读取三处 `Uninstall` 登记（HKLM、HKLM\WOW6432Node、HKCU），过滤系统组件、更新补丁；
  Store 应用通过 PowerShell（输出 UTF-8 JSON）枚举，`PackageFullName` 严格校验字符集后才用于卸载命令。
- **运行卸载器**：整行命令交给 `cmd /D /S /C "…"`（`UninstallString` 带引号和参数，不能拆成参数数组）；
  MSI 的"修改"命令（`/I{GUID}`）自动改成"卸载"（`/X{GUID}`）；命令会在确认界面显示给用户。
- **程序仍登记着时不扫描残留**（除非强制），避免把还在用的程序当残留。
- **文件残留**：只在 `Program Files`、`ProgramData`、`AppData\Roaming/Local/LocalLow`、`Local\Programs`、
  开始菜单与桌面的快捷方式里，按名称匹配（去掉版本号/架构后缀、厂商公司后缀）。
  完全同名为高置信度；名称只是部分相同为中置信度；厂商目录只有在其中仅剩本程序时才列出；
  更长的名字（`FooBarBaz` 对 `FooBar`）不匹配；`Microsoft`、`Windows*`、`Common Files` 等保留目录永不列出。
- **注册表残留**（置信度分级，只有高置信度默认勾选）：厂商/产品键、卸载登记项、`App Paths`、
  `Run`/`RunOnce` 自启动值、安装目录已不存在的**失效服务**、指向安装目录的 **COM 注册（CLSID）**。
  依据"引用了安装目录"判断，按路径边界匹配（`C:\Foo` 不会匹配 `C:\Foobar`）。
- **注册表删除的三道保险**：
  1. **白名单**：只允许删 `Uninstall\<项>`、`App Paths\<项>`、`Classes\CLSID\{GUID}`、`SOFTWARE\<厂商>\<产品>`、
     `Services\<服务名>`，以及 `Run`/`RunOnce` 里的**值**；`Microsoft`、`Classes`、`Policies` 等保留厂商永不允许。
  2. **先备份**：删除前导出标准 `.reg`（UTF-16LE，带 BOM），双击即可恢复；备份失败则**整体中止，文件也不删**。
  3. **执行时重新校验**：服务又出现了、COM 注册改指别处、厂商键多了新内容，都会拒绝删除。
- **文件删除**沿用安全策略：默认保护名单 + 只放开应用常驻目录的内部，并把系统自带子目录重新保护；用户排除项最优先。
- 前端只回传序号，路径和注册表键都取自后端保存的扫描结果。
- 暂未做：批量卸载、"孤立残留"（没有对应程序记录的老残留）、服务/计划任务/防火墙规则/Shell 扩展的更深入清理。

## M6.5 目录迁移与占用处理
**目标**：把占空间的目录（应用安装目录、`AppData` 下的缓存/虚拟机镜像等）迁到另一个盘，
并在原位置留下 junction，程序、快捷方式、注册表里的路径照常有效，无需重装。

- **先复制、校验，再切换**（`migrate.rs`）：预检 → 复制（Windows 用 `robocopy /E /COPY:DATSO /DCOPY:DAT /XJ`，保留 ACL/所有者）→
  逐项校验（路径、类型、大小）→ 原目录**改名**为 `<名>.dc-old-<id>` → `mklink /J` 建 junction → 验证 →
  删除旧目录。改名这一步是最可靠的"是否被占用"检测：失败就回滚，原目录完好。
- **任何一步失败都回滚**：复制/校验失败清掉目标；改名失败清掉目标；建链接失败把原目录放回去；
  放不回去时在记录里写明旧目录的位置，不谎称已回滚。
- **write-ahead 清单**（`migrations.json`）：每个破坏性步骤之前先落盘状态；启动时 `recover` 根据磁盘实际情况回滚或补记完成。
  写不进清单就拒绝继续。
- **还原**：删除链接 → 复制回来 → 校验 → 删除目标；失败则恢复链接，数据留在目标。
- **预检**：源/目标是否有效、受保护（`migration_policy`：系统目录与用户根目录本身禁止，`AppData\Local\Docker` 这类子目录允许）、
  是否嵌套、是否同卷、目标是否网络/可移动盘、源卷是否 NTFS、目标是否非空、是否含链接或云占位文件（暂不支持，避免迁移后失效）、空间是否足够（含余量）。
  程序安装目录和超大数据量只给警告。
- **占用检测**（`procs.rs`）：① 可执行文件在该目录内的进程；② 当前工作目录在该目录内的进程；
  ③ Restart Manager 报告的"打开了其中文件"的进程与服务。显示进程名、PID、原因、服务名。
- **相关进程**：子孙进程；以及与占用者同一安装目录的其他进程（系统目录里的进程不算，避免把整个 System32 当成"相关"）。
- **停止进程**：先礼貌关闭（`taskkill /PID`），超时后**仅在用户勾选"强制"时**才 `/F`；服务通过 `sc stop` 释放；
  子进程先于父进程。**永远不碰**：系统关键进程、资源管理器（提示用户关闭窗口）、本程序自身、不知道具体服务的 `svchost`。
  前端只能传 PID，后端只处理上一次检测列出的进程；执行前会核对 PID + 启动时间 + 名称，防止 PID 被复用后误杀。
- 暂不支持：含符号链接/junction 的目录、云占位文件、商店应用（`WindowsApps` 受系统保护）、复制阶段之外的取消。

## 界面
- 树视图按文件类型显示图标（目录开合、文件按扩展名着色，注册表键值有专用图标）。
- **候选清单**：在树视图里把文件/目录加入候选，随时展开整体检查（完整路径、大小、重复包含关系只算一次），
  可一并移入回收站/删除，或把单个目录交给"目录迁移"。前端只传扫描树里的路径分量，真实路径由后端解析。
- "最大的文件"列表：文件名单独一行，所在目录完整显示并在 `\` 处换行；可复制完整路径、定位、加入候选。

## 清理后立即刷新视图
任何改变磁盘内容的操作（清理规则、候选清单、重复文件、卸载与残留清理、迁移与还原、系统工具）完成后，
界面立刻反映，**不需要重新扫描**：
- 后端直接在内存里的扫描树上删除/替换对应节点，并沿途修正所有上级目录的大小、文件数和排序
  （`scanner::remove_path` / `replace_path`）；迁移成功后源目录从树里去掉，还原后重新遍历该目录接回树里。
- 树视图、合计、最大文件列表、树图、概览页的磁盘可用空间、重复文件结果都订阅同一个"有变化"信号；
  树的展开状态保存在组件之外，刷新不会把已展开的目录收起。
- 候选清单只移出已处理的项；被拒绝或失败的留在清单里，让用户看到并决定。
- 重复文件的选择会同时回传路径，别处清理让序号错位时后端拒绝，而不是删到别的文件。

## 编码与文件名显示
- 内部全程 UTF-16/UTF-8 字符串，不依赖系统代码页；日志是 UTF-8（中文原样可读，不转义成 `\uXXXX`），
  注册表备份是带 BOM 的 UTF-16LE（emoji 的代理对也能还原）。
- **外部工具的输出**（`taskkill`、`sc`、`mklink`、`DISM` 等）走控制台 OEM 代码页（中文系统是 GBK）：
  能按 UTF-8 解就按 UTF-8，否则调用 `MultiByteToWideChar(CP_OEMCP)` 解码，错误详情里的中文不再乱码。
  PowerShell 输出显式设为 UTF-8。
- 文件名不合法（Windows 上未配对的代理项，Linux 上非 UTF-8 字节）：扫描照常统计并用替换字符显示，
  清理时因无法做安全校验而**跳过**，绝不删除。
- 界面：长路径用 `<wbr>` 提供换行位置，**不往文字里插入任何字符**（早先用零宽空格会让复制出来的文件名带上不可见字符）；
  等宽字体后补了中日韩与 emoji 的回退字体。
- 测试覆盖：中日韩、阿拉伯、泰文、emoji、全角符号、预组合与分解形式的重音字符、不合法编码，
  贯穿扫描、重复文件、复制校验、清理日志、规则、注册表备份与界面。

## 云端硬盘与同步目录不参与分析
云盘里的内容大多不占本机空间（"仅在线"占位文件）或只是同步副本，混进"谁占了我的磁盘"会误导；
遍历虚拟盘符还很慢，甚至触发网络访问。所以**默认不分析**（`cloud.rs`）：
- **识别**：已知的同步目录名（Google Drive、OneDrive*、Dropbox*、iCloud、群晖 Drive、坚果云、百度网盘、阿里云盘、Box Sync、MEGAsync、pCloud、Yandex Disk）、
  `OneDrive*` 环境变量给出的精确路径、卷标为云盘的虚拟盘符（如 Google Drive 桌面版）、网络驱动器、用户自定义的跳过路径。
  宁可少排除：`Box`、`Mega Games`、`Documents` 这类普通名字不会被误判。
- **遍历扫描**：直接不进入这些目录；**MFT 快速扫描**一次读出整个卷，所以事后把它们从树里剪掉，并从所有上级扣除大小。
  被排除的目录在结果里列出（可展开查看），合计、最大文件、树图都不含它们。
- **重复文件**同样跳过，云盘里的副本不会被当作"可删除的重复"。
- **扫描位置本身**在云端或网络盘上时直接拒绝，并说明原因；概览页隐藏这类盘符并给出一行说明。
- **目录迁移**：云同步目录**永远不能迁移**（搬走会破坏同步），与"是否分析云端"的设置无关。
- **设置**：可打开"也分析云端硬盘和同步目录"；可添加额外要跳过的完整路径（无论是否分析云端都生效，无效路径会被拒绝而不是静默无效）。
- 注意：群晖 Drive 等私有云的本地同步目录里是**真实占用本机空间的副本**，默认也被排除；
  想看它们占了多少，在设置里打开"分析云端"即可。

## macOS 支持（v0.2）

目标：macOS 11+（Apple 芯片与 Intel，通用二进制）。核心库与 UI 复用，平台差异用依赖注入隔离，
所以绝大部分逻辑可以在 Linux 上以 `PathStyle::Mac` 做集成测试。

| 能力 | Windows | macOS |
| --- | --- | --- |
| 路径安全 | `PathStyle::Windows`（盘符、大小写不敏感） | `PathStyle::Mac`（`/`、大小写不敏感）；保护 `/System`、`/usr`、`/Library`、`/Applications`、主目录及文档类目录，`~/Library` 整体保护，缓存等由规则逐个放开 |
| 磁盘分析 | MFT 快速扫描，失败回退遍历 | 并行遍历，大小取实际占用（`st_blocks`）；跳过 `/System/Volumes`、`/Volumes`、`/dev`、交换文件，避免重复计数；默认分析主目录 |
| 清理规则 | `%TEMP%` 等 | `%HOME%/Library/Caches`、`Logs`、浏览器缓存、废纸篓、Xcode、开发缓存、iOS 备份（默认只勾选低风险项） |
| 系统工具 | 回收站、休眠、DISM、`Windows.old`、卷影副本 | Time Machine 本地快照（经系统授权对话框）、`brew cleanup`、删除不可用的 iOS 模拟器 |
| 应用卸载 | 注册表 + 卸载器，残留含注册表项 | 枚举 `/Applications` 与 `~/Applications` 的 `.app`；卸载 = 移入废纸篓；残留在 `~/Library` 的固定子目录里按 **Bundle ID（高）/ 应用名（中）** 精确匹配，苹果自己的应用不提供清理 |
| 目录迁移 | junction + robocopy | 符号链接 + `ditto`（保留权限、扩展属性、资源分支与内部符号链接）；外置磁盘只提示；目标必须是 APFS/HFS+；路径不经命令解释器 |
| 占用检测 | Restart Manager + 进程 cwd/exe | `lsof` + 进程 cwd/exe；结束进程用 SIGTERM → SIGKILL，`Finder`、`WindowServer`、`launchd` 等受保护 |
| 云盘排除 | OneDrive 等目录名与环境变量 | 另加 `~/Library/Mobile Documents`（iCloud）与 `~/Library/CloudStorage/*`（文件提供程序） |
| 权限 | 管理员 manifest；非管理员时提示重新启动 | 不需要 root；缺少“完全磁盘访问权限”时提示并一键打开系统设置 |
| 显示 | 资源管理器、回收站 | 访达（`open -R`）、废纸篓；文案用 `key.mac` 覆盖 |

已知限制：APFS 克隆文件会被分别计数；`~/Library/Containers` 等沙盒与同步目录不允许迁移；
未公证的 .dmg 需要用户手动放行（见 docs/release.md）。
